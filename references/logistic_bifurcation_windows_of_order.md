# logistic_bifurcation_windows_of_order.png

The logistic-map bifurcation diagram, `x -> r*x(1-x)`, `r` in [1,4] (x-axis),
attractor `x*` (y-axis). Source: substack post media (fetched 2026-08-31).

The white lens-shaped gaps in the black chaotic band are the **windows of
order** / bubbles of order — connected regions where the attractor is a
stable p-cycle. Period-3 is the wide one near r = 3.83; smaller period-5,
period-6 windows are scattered through the chaos.

Reference for:
- FourthAgePapers/HyperBifurcation (windows of order = Feigenbaum RG fixed
  points; buoyancy + wake; the 3-D bifurcation)
- the n-ball / {4:8:4} connection: a window of order IS an n-ball in the full
  parameter space (its skin an (n-1)-sphere = the crisis boundary); V(n) =
  pi^(n/2)/Gamma(n/2+1) is itself a one-window bifurcation curve, peaked at
  n* ~ 5.257, collapsing to 0 -- order is measure-zero in high dimensions.
